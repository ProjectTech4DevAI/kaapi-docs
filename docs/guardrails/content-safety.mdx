# Content Safety

**Runs on incoming messages**

Removes abusive or hurtful words from messages before the assistant reads them.

## What happens

**↻ Fixes & passes on** — A listed slur is hidden and the message continues as normal. A message the AI check rates as toxic is replaced as a whole.

## Example

| | |
| --- | --- |
| **User** | `Don't be such an <slur>, you know?` |
| **Assistant sees** | `Don't be such an [REDACTED_SLUR], you know?` |

The word is hidden before the assistant reads the message. If the AI check also rates the whole message as toxic, the whole message is replaced with your set reply instead.

:::info

Tested on English, Hindi and Hinglish. Other languages are not tested.

:::

## Without this guardrail

:::danger

The abusive word reaches the assistant, and may appear again in the reply. **Risk:** abusive language is not stopped, which hurts trust and looks bad for your organisation.

:::

## Settings

Validator: `content_safety`. It runs two checks on the original message: a list of English and Hindi slurs, and an AI model (`textdetox/bert-multilingual-toxicity-classifier`) that scores how toxic the whole message is.

| Setting | Values | What it does |
| --- | --- | --- |
| `slur_severity` | `low`, `medium`, `high`, `all` (default `all`) | Minimum slur severity to hide. |
| `threshold` | `0`–`1` (default `0.5`) | Toxicity score at which the whole message is replaced. Raising it removes some false alarms, but not many. |
| `fallback_message` | text, optional | What the assistant sees or the user gets instead of a toxic message. If empty, the message is blanked. |

## How well it works

<MetricsHeadline validator="content_safety" />

Tested on real-style messages in English, Hindi and Hinglish.


## Known limitations

:::warning

- **More false alarms than before.** About 1 in 5 flagged messages is actually clean, mostly everyday Hinglish chat and some political Hindi. Part of this is label noise in the test set.
- **A toxic message is replaced as a whole**, not word by word. Set `fallback_message` for each bot.
- **Indirect insults are missed**, especially Hindi political ones with no abusive words.
- **It is slower** than a word list: an AI model runs on every message, and needs a one-time model download of about 700 MB.

:::
