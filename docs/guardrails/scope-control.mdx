# Scope Control

**Runs on incoming messages**

Stops the assistant from answering questions about topics you choose. For example, a maternal-health assistant will not give legal or financial advice.

## What happens

**⊖ Blocks — sends set reply** — The message never reaches the AI assistant. The user gets the set reply you've written in the settings.

## Example

| | |
| --- | --- |
| **User** | `Is it okay to take this medicine?` |
| **Assistant replies** | `Sorry, I can't help with that topic. I can only answer questions related to this programme.` |

These questions are stopped before the assistant answers them.

:::info

Your set reply is automatically translated by AI to match the language the user wrote in — a Hindi message gets the reply in Hindi, an English one in English.

:::

## Without this guardrail

:::danger

The assistant answers questions it should stay away from. **Risk:** users may get wrong advice on serious topics like health or money.

:::

## Settings

Validator: `topic_relevance_llm`. One AI call scores each message from 1 (clearly out of scope) to 3 (clearly fine).

| Setting | Values | What it does |
| --- | --- | --- |
| `configuration` | text | The topics you list, written in plain language. |
| `prompt_schema_version` | `1` allowed topics, `2` forbidden topics (default), `3` both | How the topic text is read. |
| `threshold` | `1`–`3` (default `2`) | `3` also blocks ambiguous messages. |
| `fallback_message` | text, optional | The set reply sent when a message is blocked. |

The check fails closed: if the configuration is empty or the AI call fails, the message is blocked.

## How well it works

<MetricsHeadline validator="topic_relevance_llm" />

Tested on real-style messages across education and healthcare topics, in English, Hinglish and Hindi.


## Known limitations

:::warning

- **Each check is an AI call, so it is much slower than the other guardrails** and needs an OpenAI key.
- **Beauty and weight questions in healthcare often get through**.
- **Some valid questions are blocked**, e.g. "where can I get my baby's vaccination near my village?".

:::
