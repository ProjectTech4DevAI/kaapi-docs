# Welcome to Kaapi

Our open-source AI middleware enables NGOs to build, evaluate, and ship LLM-powered features through a unified interface — multi-provider, multimodal, and built around the workflows the social sector actually runs.

## What you can do

- 🔌 **Talk to every major LLM provider** through one consistent API
- 🎙️ **Build multimodal experiences** — text, image, document, voice
- 📊 **Run structured evaluations** and pick configurations with evidence
- 🛡️ **Ship safely** with built-in guardrails for PII, toxicity, topic relevance, and more
